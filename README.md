# STRETCH International Website

A modern, premium website for STRETCH International built with React, TypeScript, and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository or extract the ZIP file.
2. Navigate to the project directory:
   ```bash
   cd stretch-intl
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development
Start the development server:
```bash
npm run dev
```
The site will be available at `http://localhost:5173`.

### Build
Create a production build:
```bash
npm run build
```
The build files will be in the `dist` folder.

## 🛠 Tech Stack
- **Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM

## 📁 Project Structure
- `src/components`: Reusable UI components (Navbar, Footer, HeroSlider, etc.)
- `src/pages`: Main page components (Home, Impact Hub, Solutions Lab, etc.)
- `src/assets`: Images and static assets.
- `.vscode`: Workspace settings and recommendations for VS Code users.

## ✨ Features
- Fully responsive design.
- Premium glassmorphic UI.
- Interactive Hero slider.
- Dynamic page routing.
- Integrated partnership and service forms.
